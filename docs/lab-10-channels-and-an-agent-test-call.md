# Lab 10: Channels and an agent test call

In this lab, you will learn how to connect calls to the flow and to receive a call on an Agent Desktop.

### Callers to Yellow Brick Bank’s support number should hear the menu options

Contact Center > Customer Experience > Channels > Create a channel

* Name: Main Number
* Type: Inbound Telephony
* Service Level: 120
* Timezone: NewYork
* Routing Flow: PrincipalMenu
* Music On Hold: defaultmusic\_on\_hold.wav
* Version Label: Latest
* Phone numbers: Add
  + Webex Calling location: dCloud
  + PSTN number: Select one from dropdown
  + Make a note of the number
