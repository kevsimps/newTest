# Lab 2: Assigning agent licenses

In this lab, you will learn to assign Contact Center agent licenses to users.

### The existing users need premium licenses to have the permission and tools required for their roles.

Management > Users > Licenses > Organization-based licenses > Set up

Organization licenses assignment

* Contact Center
  + Licensed Agent: Premium Agent
  + Apply scope
    - Existing users (You may need to scroll down on the page to see this)
    - Preserve licenses for existing users
