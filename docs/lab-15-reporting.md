# Lab 15: Reporting

In this lab, you will learn how to run a report and create a desktop of reports.

### Supervisors need to analyze data about queues.

Contact Center > Overview > Analyzer > Visualization

* Select Stock Reports
* Select Historical Reports
* Select Queue Reports
* Run Queue Activity by Queue
* Duration: This Week

### Supervisor would like to see a view of multiple queues on one screen.

Contact Center > Overview > Analyzer > Dashboard

* Create a new Dashboard
* Name: Dashboard Queues
* Add: Queue Activity by Queue
* Add Agent Detail Report
* Save and run the dashboard
* Duration: This Week
