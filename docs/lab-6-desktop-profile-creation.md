# Lab 6: Desktop Profile creation

In this lab, you will learn how to create desktop profiles. **Note: If a configuration option in Control Hub is not mentioned in the lab, skip that option.**

### Agents should have access only to features necessary for their roles on their desktops.

Contact Center > Desktop Experience > Desktop Profiles

**General tab**

* Name: YBB Desktop Profile
* Parent type: Site
* Site: YBB HQ
* Screen Popups: enabled

**Idle/Wrap-up Code tab**

* Wrap-up codes
  + Auto wrap-up with timeout of 60 seconds
  + Auto wrap-up extension: enable

**Collaboration tab**

* Entry point/ Queue transfer targets: None
* Buddy Teams: Enable Specific
* Add: Corporate and Investment Teams

**Voice**

* No changes

**Agent Statistics**

* Agent Statistics: Enable

**Desktop Timeout**

* No changes
